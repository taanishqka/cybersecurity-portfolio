# Botium Toys – Cybersecurity Risk Assessment

## Project Overview
This project is based on the Botium Toys security audit activity from the Google Cybersecurity Professional Certificate.

The objective was to assess an organisation's existing security controls, identify potential risks and evaluate selected compliance practices.

## Objectives
- Identify existing security controls.
- Identify security weaknesses and vulnerabilities.
- Review PCI DSS, GDPR and SOC-related best practices.
- Understand the importance of risk management.

## Scope
The assessment considered:
- Employee and customer information.
- Company computers and devices.
- Network and security infrastructure.
- Physical security.
- Data protection practices.

## Key Findings
Some identified security gaps included:
- Lack of least-privilege access.
- Missing intrusion detection system.
- Lack of regular data backups.
- Inadequate encryption of sensitive information.
- No disaster recovery plan.

## Security Controls Reviewed
- Firewall
- Antivirus software
- Password policies
- Encryption
- Backups
- Access controls
- CCTV surveillance
- Physical security

## Learning Outcomes
Through this activity, I learned how to:
- Conduct a basic security audit.
- Identify security risks.
- Evaluate security controls.
- Understand compliance frameworks.
- Recommend improvements to an organisation's security posture.
